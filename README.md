# Coding Interview

面试题库仓库，每道题一个目录，目录内提供一份可直接打开的原型 HTML 作为需求载体。

## 题目列表

| 目录 | 题目 | 原型入口 |
| --- | --- | --- |
| [`PPT/`](./PPT) | AI 写作助手：导入写作素材、引用知识库，由 AI 生成演讲文稿 / 通用文稿 / 思维导图等产出 | [`PPT/index.html`](./PPT/index.html) |
| [`Data/`](./Data) | 数据问答：企业级销售经管数据管理平台 | [`Data/index.html`](./Data/index.html) |

## 面试方式

每道题的原型 `index.html` 仅作为产品原型参考，候选人**不要改动该文件**，需自行新增代码实现完整功能。面试时进行 Code Review。

题目详情见各题目目录下的 `README.md`（如有）。

## 预览

直接用浏览器打开对应目录下的 `index.html`，无需构建。
